# AuditMaster

Centralized Linux Security Auditing and Monitoring Platform.

## Technologies
- Ubuntu Linux
- Auditd
- AIDE
- Samba
- Ansible
- Prometheus
- Node Exporter
- Grafana

## Features
- Department-based access control
- File activity monitoring
- File integrity checking
- Secure file sharing
- Automated security checks
- System monitoring

## Project Structure
- AuditMaster/ansible - Ansible playbooks
- AuditMaster/scripts - Security scripts
- AuditMaster/config - Configuration files
- AuditMaster/reports - Reports
